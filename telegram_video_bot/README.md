# Telegram-бот для сповіщень про нові відео

Бот на Python та aiogram 3 перевіряє відкриті профілі TikTok через `yt-dlp`
і надсилає адміністраторам прев'ю та посилання на нові відео.
Кнопка під сповіщенням завантажує публічне відео й надсилає його в Telegram.
Адміністратори також можуть надсилати боту фото, відео або команду `/save URL`
для обробки. Профілі та історія відео зберігаються у Supabase.

## Налаштування

1. Створіть бота через [@BotFather](https://t.me/BotFather) і скопіюйте токен.
2. У Supabase відкрийте **SQL Editor**, виконайте вміст
   `telegram_video_bot/supabase_schema.sql`.
3. У Railway відкрийте **Variables** сервісу та задайте:

   - `BOT_TOKEN` — токен Telegram-бота.
   - `ADMIN_IDS` — числові Telegram user ID адміністраторів через кому.
   - `SUPABASE_URL` — Project URL із налаштувань Supabase API.
   - `SUPABASE_SERVICE_ROLE_KEY` — service-role key із налаштувань Supabase API.

   Service-role key надає повний доступ до бази: зберігайте його лише в
   Railway Variables або іншому серверному сховищі секретів. Не додавайте його
   до Git, клієнтського коду чи повідомлень.

4. Кожен адміністратор має відкрити бота в Telegram і надіслати `/start`,
   інакше Telegram не дозволить боту написати йому приватно.
5. Для локального запуску задайте ті самі значення як змінні середовища
   процесу, встановіть залежності та запустіть із кореня репозиторію:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install --upgrade pip
   pip install -r telegram_video_bot/requirements.txt
   python -m telegram_video_bot.main
   ```

Бот читає лише змінні середовища процесу й перевіряє доступ до Supabase під час
запуску. Він не завантажує налаштування з `.env`; у Railway використовуйте
**Variables**, а локально — середовище PowerShell або середовище запуску IDE.
Для перевірки доступності Railway-сервіс слухає порт `PORT` і повертає `ok` за
адресами `/` та `/health`. Це підтверджує роботу HTTP-процесу, але не доступність
Telegram чи Supabase і не обходить ліміти тарифу Railway.

## Меню в Telegram

Натисніть `/start`, щоб відкрити головне inline-меню. Керування профілями
виконується кнопками; елементи керування не публікуються як slash-команди.
Доступ до адміністративних кнопок і обробки медіа мають лише ID з `ADMIN_IDS`.
Сповіщення надсилаються приватно всім адміністраторам; окремий
`TELEGRAM_CHAT_ID` не потрібен.
Кнопки меню перемикають розділи в одному повідомленні. Щоб додати профіль,
натисніть **«Додати профіль»** і надішліть його `@нік` або URL. Щоб видалити,
відкрийте **«Мої профілі»** і натисніть 🗑 поруч із потрібним профілем.
Щоб завантажити окремий ролик, натисніть **«Скачать видео по ссылке»** й
надішліть посилання; також можна просто надіслати посилання TikTok у чат.

Під час додавання профілю його наявні відео записуються як початкова історія,
тому сповіщення починаються з наступних публікацій. Якщо профіль уже існує,
повторне додавання не створює дублікат.

## Збереження й обробка медіа

- Під сповіщеннями є кнопка **Зберегти відео**. Відео завантажується лише після
  натискання, обробляється базовими фільтрами й надсилається як файл Telegram.
- Адміністратори можуть використати кнопку **«Скачать видео по ссылке»** й
  надіслати URL, або просто відправити посилання на публічне відео в чат.
- Відео та фото, надіслані адміністратором боту, автоматично обробляються.
- Максимальний вхідний файл — 20 МБ; файл TikTok і результат — до 45 МБ.
  Для відео, яке після обробки перевищує ліміт, бот намагається надіслати
  оригінал. Фото/відео без підтримуваного формату, приватні чи недоступні відео
  обробити не вийде.
- Фото отримують легке коригування кольору, контрасту й різкості; відео —
  зниження шуму та легке підвищення різкості. Це звичайні безкоштовні фільтри,
  а не AI-super-resolution: вони не створюють відсутні деталі й не перетворюють
  матеріал на справжнє 4K. Відео зберігає початкову роздільність.
- Для локального запуску потрібен FFmpeg у `PATH`. Docker-образ Railway
  встановлює FFmpeg автоматично. Railway та безкоштовні тарифи хостингу можуть
  обмежувати тривалість роботи, CPU, пам'ять і мережу; це не гарантія
  необмеженого безкоштовного завантаження.

## Налаштування моніторингу

- `POLL_INTERVAL_SECONDS` — інтервал перевірки; мінімум 60 секунд, типовий —
  900 секунд.
- `MAX_VIDEOS_PER_PROFILE` — скільки останніх відео читати за цикл (1–50,
  типовий — 20).

Схема Supabase має бути створена до запуску. Дані з попередньої локальної
SQLite-бази автоматично не переносяться.

TikTok іноді блокує або змінює доступ до публічних метаданих. У такому разі
бот запише помилку в лог і повторить перевірку під час наступного циклу. Він
не обходить приватність профілів чи обмеження доступу.
